## 채권 데일리 코멘트 작성 규칙

### 검색 (전일 = 직전 영업일 기준, 오늘 날짜가 D일이면 D-1일 시장)
1. 미국채: WebSearch "뉴스핌 채권/외환 미 국채 {D-1}일(현지시간) 10년물 2년물 30년물"
   → newspim.com 기사 중 제목이 [채권/외환]으로 시작하는 당일 아침 기사를 전문 읽기
2. 국고채: WebSearch "국고채 금리 마감 {M}월 {D-1}일 3년물 10년물 30년물 서울 채권시장"
   → specialtimes.co.kr 기사 전문 읽기
3. 환율: WebSearch "원·달러 환율 오전 9시경 {D}일" (데일리안)
   + WebSearch "원/달러 환율 {D-1}일 마감 1,3" (종가)
4. 추가 맥락이 필요하면: WebSearch "미 국채금리 {D-1}일(현지시간) 마감" 으로 2~3개 기사 교차 확인.
   수치가 기사마다 다르면 뉴스핌(트레이드웹 기준)을 우선.

### 구조 (3단락, 줄바꿈으로 구분, 총 400~600자)
[1단락 미국채] 방향 한 문장 → 원인(지표·연준 발언·유가·수급) → 2/10/30년 마감 수치와 bp 변동
   → 커브 모양(스티프닝/플래트닝) → 다음 이벤트 한 줄
[2단락 국고채] 방향 한 문장 + 원인 → (2년 x.xxx%, ±bp / 10년 / 30년) 괄호 표기
   → 외국인 국채선물 순매수/순매도 계약수 → 정책·수급 뉴스(바이백, 발행계획)가 있으면 한 줄
[3단락 환율] 9시 값 + 전일 대비, 마감치 있으면 함께, 원인 한 줄

### 문체
- 종결어미는 "~하였음", "~기록하였음", "~보임" 체. "~했다/~이다" 금지.
- 숫자: 금리는 소수점 셋째 자리(5.243%), 변동은 bp, 환율은 천단위 콤마(1,358.6원).
- 사실만 쓰고 전망·추천은 쓰지 않음. "~로 보임"은 시장 컨센서스를 옮길 때만.
- 기사 문장을 그대로 복사하지 말고 재구성. 수치 출처가 불확실하면 그 수치는 빼고 방향만 서술.
- 환율 마감치를 못 찾으면 9시 값만 쓰고 생략했다고 사용자에게 알릴 것.

### 주의
- 토요일·월요일 작성 시 D-1은 금요일 시장(미국은 금요일 현지 마감).
- 미국 고용·CPI·FOMC 날은 해당 지표 수치와 시장 반응을 1단락 첫 두 문장에 넣을 것.
- 투자 판단 자료이므로 수치를 추정해서 채우지 말 것. 못 찾으면 공란 + 보고.

### 작업 메모 (환경)
- WebFetch는 newspim/specialtimes/dailian이 차단되어 있어, Bash의 curl로 기사 HTML을 받아 본문(<article>, #article-view-content-div)을 추출해 읽는다.
  specialtimes는 `curl --http1.1 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/124"` 로만 접속됨.
- 엑셀 수정은 openpyxl 대신 XML 직접 수정(차트 보존). 코멘트는 sharedStrings.xml의 해당 문자열(C47) 교체.
